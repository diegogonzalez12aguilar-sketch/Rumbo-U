# RumboU

App de estudio para tu examen de admisión — unidad piloto: Ecuaciones.

## Cómo publicarla (GitHub + Vercel)

1. Crea un repositorio nuevo en GitHub (por ejemplo `rumbou`).
2. Sube TODOS estos archivos y carpetas manteniendo la misma estructura
   (incluida la carpeta `src/`).
3. Entra a Vercel → "Add New" → "Project" → elige el repositorio `rumbou`.
4. Vercel detecta automáticamente que es un proyecto Vite. Deja la
   configuración por defecto y da clic en "Deploy".
5. En un par de minutos te da un link como `rumbou.vercel.app` — esa es
   tu app publicada.

Cada vez que subas cambios nuevos a GitHub, Vercel vuelve a publicar la
página sola, sin que hagas nada más.
